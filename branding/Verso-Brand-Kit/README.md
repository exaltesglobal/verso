# Verso Brand Kit v1.0

Verso, the desktop video editor by Agape Labs (Exaltes Global Private Limited).
Tagline: **Long videos in. Reels out.**

Start with `05-Guidelines/Verso-Brand-and-UI-Guidelines.pdf` (or the .html, which works offline).

| Folder | What's inside |
|---|---|
| 01-Logo | Mark, horizontal and stacked lockups, wordmark. SVG (text outlined, no font needed) and PNG. |
| 02-App-Icon | `verso.ico` (Windows), `verso.icns` (Mac), PNG 16 to 1024px, master SVGs (use `verso-app-icon-small.svg` at 32px and below). |
| 03-Iconography | 36 UI icons, SVG, 24px grid, 1.75 stroke, `currentColor`, plus `icon-sheet.png`. |
| 04-Design-Tokens | `verso-tokens.css`, `verso-tokens.json`, `verso-tailwind-preset.js`. |
| 05-Guidelines | Brand and UI/UX guidelines (HTML and PDF). |
| 06-UI-Mockups | Editor screen mockup. |
| 07-Social | Instagram post, feature post and story, YouTube banner, X and LinkedIn headers, profile avatar, website share image, app splash screen. |

## Core colours
- Ember `#FF4A2B` (primary action, playhead, logo)
- Glow `#FF9466` (gradient partner, focus ring)
- Ink `#0B0B0F` (app background)
- Paper `#F5F4F0` (text, light backgrounds)

## Typeface
Manrope (free, Google Fonts, SIL Open Font License). Headlines ExtraBold 800 with -4% to -5% tracking; UI Medium 500 and SemiBold 600.
